Settings

Proxy / VPN

Route all browser traffic through a SOCKS5 or HTTP proxy. Works with VPN providers that offer proxy endpoints (Mullvad, Proton, NordVPN, etc.), a local Tor daemon (socks5://127.0.0.1:9050), or a WireGuard/OpenVPN client exposing a local SOCKS port. Xer does not operate VPN servers itself.

DNS & ad blocking

Ad and tracker blocking is always on (Ghostery engine with EasyList and EasyPrivacy).

Extensions

Load unpacked Chrome extensions (Manifest V2 or V3). Click Add, pick the folder that contains manifest.json, and review the permissions before confirming. Only add extensions you trust: they can see the pages they have access to. Not every Chrome extension API is supported by Electron.

Gaming / Cloud gaming

Removes the browser's own bottlenecks so a cloud-gaming stream (GeForce NOW, Xbox Cloud Gaming, Luna, Shadow) is shown at its full rate with low latency. The stream's frame rate itself is set by the cloud server and your connection, so no browser can guarantee a specific number. Toggle Game Mode any time with Ctrl+Shift+G.

AI assistant

Install Ollama, then run ollama pull llama3.2 (or any model you like). Nothing leaves your machine.
